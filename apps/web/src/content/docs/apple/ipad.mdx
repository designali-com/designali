## Usage

```tsx showLineNumbers
import { IPad } from "@/components/ui/ipad"
```

```tsx showLineNumbers
<IPad>
  <div className="p-6">Your content here</div>
</IPad>
```

### Variant

```tsx showLineNumbers
<IPad variant="ipad-air" color="blue">
  <div className="p-6">iPad Air</div>
</IPad>
```

### Orientation

```tsx showLineNumbers
<IPad orientation="landscape">
  <div className="p-6">Landscape iPad</div>
</IPad>
```

### Size

```tsx showLineNumbers
<IPad size="lg">
  <div className="p-6">Large iPad</div>
</IPad>
```

### Color

```tsx showLineNumbers
<IPad variant="ipad-pro" color="black">
  <div className="p-6">Space Black iPad Pro</div>
</IPad>
```

### Custom frame image

```tsx showLineNumbers
<IPad
        variant="ipad-air"
        color="blue"
        size="lg"
      >
        <img
          src="/img/login-1.jpg"
          alt="App screen"
          className="h-full w-full object-cover"
        />
      </IPad>
```

## Props

| Prop          | Type                                                                          | Default       |
| ------------- | ----------------------------------------------------------------------------- | ------------- |
| `children`    | `ReactNode`                                                                   | —             |
| `className`   | `string`                                                                      | —             |
| `variant`     | `"ipad-pro" \| "ipad-air"`                                                    | `"ipad-pro"`  |
| `size`        | `"sm" \| "md" \| "lg" \| "xl"`                                                | `"md"`        |
| `orientation` | `"portrait" \| "landscape"`                                                   | `"portrait"`  |
| `color`       | `"black" \| "silver" \| "purple" \| "space-grey" \| "starlight" \| "blue"`    | `"silver"`    |                                                                     | `"iPad"`      |

## Available colors

| Variant     | Colors                                       |
| ----------- | -------------------------------------------- |
| `ipad-pro`  | `black`, `silver`                            |
| `ipad-air`  | `purple`, `space-grey`, `starlight`, `blue`  |

## Notes

- The screen area is an absolutely positioned container, so `children` scroll vertically inside it when they overflow.
- The iPad is sized by height, and the width follows from the aspect ratio (`3/4` in portrait, `4/3` in landscape).
- If the selected `color` isn't available for the chosen `variant`, the first color of that variant is used. For example, `variant="ipad-air"` with the default `silver` falls back to `purple`.
- Passing `image` overrides both `variant` and `color`.
