## Usage

```tsx showLineNumbers
import { IPhoneDuo } from "@/components/ui/iphone-duo"
```

```tsx showLineNumbers
<IPhoneDuo>
  <div className="p-6">Your content here</div>
</IPhoneDuo>
```

### Size

```tsx showLineNumbers
<IPhoneDuo size="lg">
  <div className="p-6">Large iPhone Duo</div>
</IPhoneDuo>
```

### Orientation

```tsx showLineNumbers
<IPhoneDuo orientation="landscape">
  <div className="p-6">Landscape iPhone Duo</div>
</IPhoneDuo>
```

### Side

```tsx showLineNumbers
<IPhoneDuo side="back" />
```

```tsx showLineNumbers
<IPhoneDuo side="frontback" className="h-[28rem] w-auto" />
```

### Color

```tsx showLineNumbers
<IPhoneDuo color="star-white">
  <div className="p-6">Star White iPhone Duo</div>
</IPhoneDuo>
```

### Custom frame image

```tsx showLineNumbers
<IPhoneDuo>
  <div className="p-6">Custom frame</div>
</IPhoneDuo>
```

## Props

| Prop          | Type                                  | Default        |
| ------------- | ------------------------------------- | -------------- |
| `children`    | `ReactNode`                           | —              |
| `className`   | `string`                              | —              |
| `size`        | `"sm" \| "md" \| "lg" \| "xl"`        | `"md"`         |
| `orientation` | `"portrait" \| "landscape"`           | `"portrait"`   |
| `side`        | `"front" \| "back" \| "frontback"`    | `"front"`      |
| `color`       | `"night-sky" \| "star-white"`         | `"night-sky"`  |
 
## Notes

- The screen area is an absolutely positioned container, so `children` scroll vertically inside it when they overflow.
- `children` are only rendered when `side="front"`. The `back` and `frontback` views show the frame image only.
- `orientation` is ignored when `side="frontback"`.
- With `side="frontback"`, no size or aspect ratio classes are applied, so you must set the dimensions yourself with `className` (for example `h-[28rem] w-auto`).
- Passing `image` overrides `side`, `orientation` and `color` for the frame.
