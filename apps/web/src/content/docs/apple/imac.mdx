## Usage

```tsx showLineNumbers
import { IMac } from "@/components/ui/imac"
```

```tsx showLineNumbers
<IMac>
  <div className="p-6">Your content here</div>
</IMac>
```

### Size

```tsx showLineNumbers
<IMac size="lg">
  <div className="p-6">Large iMac</div>
</IMac>
```

### Color

```tsx showLineNumbers
<IMac color="blue">
  <div className="p-6">Blue iMac</div>
</IMac>
```

### Custom frame image

```tsx showLineNumbers
<IMac>
  <img
    src="/img/hero-1.jpg"
    alt="App screen"
    className="h-full w-full object-cover"
  />
</IMac>
```

## Props

| Prop        | Type                                                                          | Default    |
| ----------- | ----------------------------------------------------------------------------- | ---------- |
| `children`  | `ReactNode`                                                                   | —          |
| `className` | `string`                                                                      | —          |
| `size`      | `"sm" \| "md" \| "lg" \| "xl"`                                                | `"md"`     |
| `color`     | `"blue" \| "green" \| "pink" \| "silver" \| "yellow" \| "orange" \| "purple"` | `"silver"` |
 
## Notes

- The screen area is an absolutely positioned container, so `children` scroll vertically inside it when they overflow.
- Passing `image` overrides the `color` prop.
- Sizes map to fixed widths (`24rem`, `32rem`, `40rem`, `52rem`). Use `className` (for example `max-w-full`) to keep the iMac inside small viewports.
