## Usage

```tsx showLineNumbers
import { StudioDisplay } from "@/components/ui/studio-display"
```

```tsx showLineNumbers
<StudioDisplay>
  <div className="p-6">Your content here</div>
</StudioDisplay>
```

### Variant

```tsx showLineNumbers
<StudioDisplay variant="studio-display-xdr">
  <div className="p-6">Studio Display XDR</div>
</StudioDisplay>
```

### Size

```tsx showLineNumbers
<StudioDisplay size="lg">
  <div className="p-6">Large Studio Display</div>
</StudioDisplay>
```

### Color

```tsx showLineNumbers
<StudioDisplay color="light">
  <div className="p-6">Light Studio Display</div>
</StudioDisplay>
```

### Custom frame image

```tsx showLineNumbers
<StudioDisplay image="/images/my-display-frame.png" alt="Custom display frame">
  <div className="p-6">Custom frame</div>
</StudioDisplay>
```

## Props

| Prop        | Type                                           | Default              |
| ----------- | ---------------------------------------------- | -------------------- |
| `children`  | `ReactNode`                                    | —                    |
| `className` | `string`                                       | —                    |
| `variant`   | `"studio-display" \| "studio-display-xdr"`     | `"studio-display"`   |
| `size`      | `"sm" \| "md" \| "lg" \| "xl"`                 | `"md"`               |
| `color`     | `"light" \| "dark"`                            | `"dark"`             |
| `image`     | `string`                                       | —                    |
| `alt`       | `string`                                       | `"Studio Display"`   |

## Notes

- The screen area is an absolutely positioned container, so `children` scroll vertically inside it when they overflow.
- The display is sized by height, and the width follows from the aspect ratio.
- Passing `image` overrides both `variant` and `color` for the frame.
