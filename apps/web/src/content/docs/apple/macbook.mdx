## Usage

```tsx showLineNumbers
import { Macbook } from "@/components/ui/macbook"
```

```tsx showLineNumbers
<Macbook>
  <div className="p-6">Your content here</div>
</Macbook>
```

### Variant

```tsx showLineNumbers
<Macbook variant="macbook-pro" color="black">
  <div className="p-6">MacBook Pro</div>
</Macbook>
```

### Size

```tsx showLineNumbers
<Macbook size="lg">
  <div className="p-6">Large MacBook</div>
</Macbook>
```

### Color

```tsx showLineNumbers
<Macbook variant="macbook-air" color="sky-blue">
  <div className="p-6">Sky Blue MacBook Air</div>
</Macbook>
```

### Custom frame image

```tsx showLineNumbers
<Macbook>
  <div className="p-6">Custom frame</div>
</Macbook>
```

## Props

| Prop        | Type                                                                                                  | Default         |
| ----------- | ----------------------------------------------------------------------------------------------------- | --------------- |
| `children`  | `ReactNode`                                                                                           | —               |
| `className` | `string`                                                                                              | —               |
| `variant`   | `"macbook-air" \| "macbook-pro" \| "macbook-neo"`                                                     | `"macbook-air"` |
| `size`      | `"sm" \| "md" \| "lg" \| "xl"`                                                                        | `"md"`          |
| `color`     | `"sky-blue" \| "midnight" \| "starlight" \| "silver" \| "black" \| "indigo" \| "blush" \| "citrus"`   | `"silver"`      |
                                                                                           | `"Macbook"`     |

## Available colors

| Variant       | Colors                                          |
| ------------- | ----------------------------------------------- |
| `macbook-air` | `sky-blue`, `midnight`, `starlight`, `silver`   |
| `macbook-pro` | `black`, `silver`                               |
| `macbook-neo` | `silver`, `indigo`, `blush`, `citrus`           |

## Notes

- The screen area is an absolutely positioned container, so `children` scroll vertically inside it when they overflow.
- Sizes map to fixed widths (`24rem`, `36rem`, `48rem`, `64rem`) with a `16/10` aspect ratio. Use `className` (for example `max-w-full`) to keep the MacBook inside small viewports.
- If the selected `color` isn't available for the chosen `variant`, the first color of that variant is used. For example, `variant="macbook-pro"` with `color="blush"` falls back to `black`.
- `silver` exists in all three variants, so the default works everywhere.
- Passing `image` overrides both `variant` and `color`.
