## Usage

```tsx showLineNumbers
import { IPhone } from "@/components/ui/iphone"
```

```tsx showLineNumbers
<IPhone>
  <div className="p-6">Your content here</div>
</IPhone>
```

### Variant

```tsx showLineNumbers
<IPhone variant="18-pro-max">
  <div className="p-6">iPhone 18 Pro Max</div>
</IPhone>
```

### Size

```tsx showLineNumbers
<IPhone size="lg">
  <div className="p-6">Large iPhone</div>
</IPhone>
```

### Orientation

```tsx showLineNumbers
<IPhone orientation="landscape">
  <div className="p-6">Landscape iPhone</div>
</IPhone>
```

### Color

```tsx showLineNumbers
<IPhone color="burgundy">
  <div className="p-6">Burgundy iPhone</div>
</IPhone>
```

### Custom frame image

```tsx showLineNumbers
<IPhone image="/images/my-phone-frame.png" alt="Custom phone frame">
  <div className="p-6">Custom frame</div>
</IPhone>
```

## Props

| Prop          | Type                                          | Default      |
| ------------- | --------------------------------------------- | ------------ |
| `children`    | `ReactNode`                                   | —            |
| `className`   | `string`                                      | —            |
| `variant`     | `"18-pro" \| "18-pro-max"`                    | `"18-pro"`   |
| `size`        | `"sm" \| "md" \| "lg" \| "xl"`                | `"md"`       |
| `orientation` | `"portrait" \| "landscape"`                   | `"portrait"` |
| `color`       | `"black" \| "glacier" \| "silver" \| "burgundy"` | `"silver"` |
| `image`       | `string`                                      | —            |
| `alt`         | `string`                                      | `"iPhone"`   |

## Notes

- The screen area is an absolutely positioned container, so `children` scroll vertically inside it when they overflow.
- The iPhone is sized by height, and the width follows from the aspect ratio (`9/19.5` in portrait, `19.5/9` in landscape).
- All four colors are available for both variants.
- Passing `image` overrides `variant`, `orientation` and `color` for the frame.
