## Operations

| Value               | Label             | Inputs Used         |
| ------------------- | ----------------- | ------------------- |
| `sum`               | Sum               | All values          |
| `average`           | Average           | All values          |
| `min`               | Minimum           | All values          |
| `max`               | Maximum           | All values          |
| `count`             | Count             | All values          |
| `add`               | Add               | First two values    |
| `subtract`          | Subtract          | First two values    |
| `multiply`          | Multiply          | First two values    |
| `divide`            | Divide            | First two values    |
| `percentage`        | Percentage        | First two values    |
| `percentage-change` | Percentage Change | First two values    |
| `remainder`         | Remainder         | First two values    |
| `power`             | Power             | First two values    |
| `sqrt`              | Square Root       | First value         |
| `absolute`          | Absolute          | First value         |
| `round`             | Round             | First value         |
| `floor`             | Floor             | First value         |
| `ceil`              | Ceiling           | First value         |
| `factorial`         | Factorial         | First value         |
| `gcd`               | GCD               | First two values    |
| `lcm`               | LCM               | First two values    |
