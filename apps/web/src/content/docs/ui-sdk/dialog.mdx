## Usage

```tsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui-sdk/dialog"
```

```tsx
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Are you absolutely sure?</DialogTitle>
      <DialogDescription>This action cannot be undone.</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose>Cancel</DialogClose>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## Notes

- There is no portal. UI SDK renders the content in the browser's top layer, so `DialogPortal` is a pass-through.
- Open and close animate with CSS transitions on `data-starting-style` and `data-ending-style`; the dialog stays mounted until the exit finishes.
- `DialogClose` takes an async `action`. The dialog stays open, with `data-pending` on the button, until the promise resolves.
